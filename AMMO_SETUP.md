# Патроны, гильзы и спуск — настройка тестовой сцены

`Scenes/SampleScene.unity` в этой ветке — **предыдущий экспорт** сцены. Если ты уже удалил объекты патрона/гильзы и подправил углы выброса или тайминги в редакторе, **не заменяй свою актуальную сцену этим файлом**. Обнови скрипты и префаб гильзы, а изменения сцены при необходимости объедини отдельно. Можешь прислать свежий `.unity`, чтобы я свёл их без потери твоих настроек.

## Что должно быть назначено в TacticalGun

- `Round Prefab`: **ассет** `Assets/Models/colt1911/bullet.prefab` (целый патрон).
- `Casing Prefab`: **ассет** `Assets/Models/colt1911/casing.prefab` (стреляная гильза). Не перетаскивай сюда объект из Hierarchy.
- `Mag Mesh`, `Ejection Point`, `Slide` и `Trigger`: существующие объекты оружия.
- `Live Round Mesh` / `Spent Casing Mesh`: если ты удалил соответствующие объекты из Hierarchy, поставь **None**. Это поля для объектов *сцены*, а не для prefab-ассетов. Префабы назначаются выше, в `Round Prefab` / `Casing Prefab`. Если сюда назначить ассет `bullet`, его масштаб будет 1 вместо масштаба пистолета 0.023 и патрон станет гигантским.

Объекты патрона и гильзы **необязательно оставлять в Hierarchy**. Если `Live Round Mesh` / `Spent Casing Mesh` не назначены, код создаст их визуальные копии из ассетов при запуске и отключит физику у копии внутри пистолета. Если оставить объекты в сцене, код воспользуется ими и отключит физику у гильзы в патроннике. Вылетевшие экземпляры остаются физическими.

Если под `mag` есть `MagazineTopPoint`, назначь именно его в поле компонента; код также умеет найти его по имени. Не оставляй в Hierarchy дублирующий `MagazineTopPoint (runtime)` после настройки. Если точки в сцене нет, она создаётся в Play Mode под магазином. Точка патронника берётся из `Live Round Mesh` или, если объект удалён, создаётся под родителем `Ejection Point`. Позиции по умолчанию рассчитаны по **старому экспорту твоей сцены** и могут не совпасть с новыми настройками. Для точной подгонки лучше создать пустые объекты-маркеры, назначить их в `Magazine Top Point` и `Chamber Point` и расположить вручную. Временные позиции можно менять параметрами `Magazine Top Local Position` и `Chamber Local Position` в Inspector. `Feed Start/End On Return` и `Feed Arc Height` настраивают движение патрона при возврате затвора.

## Проверка в Play Mode

1. Выставь `Current Mag Ammo = 3`, `Is Chamber Loaded = false`, `Is Chamber Spent = false`, `Is Magazine Inserted = true`, `Is Slide Locked = false`. Патрон логически в магазине, но при закрытом затворе **скрыт**; отведи затвор, чтобы увидеть его у верха магазина. Патронник пуст.
2. Коротко нажми `Mouse4`: при возврате затвора патрон идёт из магазина в патронник; в магазине остаётся 2. Затем стреляй (`Mouse0`): вылетает гильза и досылается следующий патрон.
3. После последнего выстрела затвор остаётся сзади. `R` меняет магазин; при закрытии затвора патрон досылается.
4. Ручное передёргивание при живом патроне должно выбрасывать **целый патрон**.
5. Зажми `Mouse0`: спуск идёт назад, курок срывается до конца хода спуска, за всё удержание происходит **один** выстрел. После отпускания спуск возвращается с задержкой (`Trigger Reset Delay`); следующий выстрел возможен лишь после отпускания и нового нажатия. Слишком короткое нажатие до `Trigger Break Fraction` не стреляет. Скорость нажатия — `Trigger Pull Duration`, скорость возврата — `Trigger Return Duration`.
6. После срыва курка патрон остаётся целым до момента удара. При откате затвора гильза сначала неподвижна относительно корпуса, затем следует за затвором и вылетает. Для настройки по порядку: `Spent Case Extraction Start` — доля хода затвора **до начала движения гильзы** (например, 0.55 = первые 55% затвор движется один); `Ejection Slide Threshold` — доля хода, при которой её можно выбросить (поставь **выше** Start хотя бы на 0.05); `Spent Case Slide Follow` (0–1) — сколько хода после начала захвата гильза повторяет; `Min Spent Extraction Time` — минимальное время с начала отката до выброса, даже если затвор уже достиг порога. С затвором на задержке ЛКМ и Shift+V не должны опускать курок.

При `Slide Blowback Speed = 33` весь откат длится примерно 0.03 с: на обычных 60 FPS промежуточные состояния почти не видны. Для визуальной настройки используй bullet time или временно замедли Blowback Speed (например, до 10–15), затем подбери Start и Threshold. Если Threshold ниже Start, код подвинет фактический порог выброса и напишет предупреждение в Console.

### Что означает задержка спуска

`Trigger Pull Duration` — время полного нажатия, а `Trigger Break Fraction` — доля пути, на которой отпускается курок. Например, 0.045 с × 0.45 ≈ 0.020 с до срыва (с поправкой на частоту кадров). После этого курок падает со скоростью `Hammer Drop Speed`, затем проходит `Ignition Delay` до вспышки. `Trigger Reset Delay` отсчитывается **после отпускания мыши**, а `Trigger Return Duration` — время движения спуска обратно; это не задержка между выстрелами. Пока ЛКМ удерживается, спуск остаётся нажатым и повторного выстрела не будет.

Проверки выполнены по коду и текстовой структуре сцены; визуальную работу нужно проверить в Unity. Отрегулируй позиции патронов, траекторию гильзы и тайминги по картинке из Game View.

### Повторные передёргивания при удержании Mouse4

`Slide Drag Sensitivity` находится в разделе `6.1 Interactive Press Check`. Это переименованный `Inspect Mouse Y Sens`, и **уже сохранённое значение из Inspector сохраняется**: если было 1.2, оно останется 1.2, несмотря на новый кодовый default 0.25. Для более точной ручной работы попробуй 0.15–0.3. При отведении затвора за `Ejection Slide Threshold` патрон/гильза выбрасывается один раз за ход назад. После достаточно полного хода (`Chambering Pull Threshold`) движением вперёд патрон досылается. Следующее движение назад вновь выбрасывает его — отпускать Mouse4 между циклами не нужно. Если передумал до окончания подачи и потянул назад, незавершённая подача отменяется без расхода патрона.

### Вращение выброшенной гильзы и звук

`Casing Ejection Rotation Offset` — фиксированный начальный поворот выброшенной **гильзы** в градусах относительно `EjectionPoint` (Y поворачивает вокруг локальной вертикали). `Casing Spin Bias Local` — фиксированная угловая скорость по локальным осям `EjectionPoint`, в **радианах/секунду**: положительный Y задаёт заворот вправо. Прежний `Ejection Spin` остаётся добавочной случайной скоростью. Эти параметры не меняют ориентацию гильзы, пока она в патроннике.

Для имеющихся файлов `Sounds/Weapons/M1911/slide/slideback2.wav` и `slidefront2.wav` назначь их в `Slide Back Clips` и `Slide Forward Clips` (или старые `slideback.wav`/`slidefront.wav`). Отдельный короткий звук целого патрона назначь в `Live Round Eject Clips`, звук гильзы — при желании в `Spent Case Eject Clips`. Пока клипы не назначены, эти события беззвучны. `Slide Audio Source` опционален: если клипы назначены, но поле пусто, код создаст отдельный `AudioSource` во время Play Mode, чтобы изменение pitch механических звуков не затрагивало хвост выстрела.

Для звука, который длится **ровно пока двигаешь затвор**, добавь отдельный `AudioSource` в `Slide Drag Audio Source` и назначь **бесшовные короткие** `Slide Back Drag Loop` / `Slide Forward Drag Loop`. Код запускает соответствующий луп при движении, останавливает при паузе или отпускании, меняет громкость и pitch по скорости мыши. Имеющиеся звуки `slideback2.wav` и `slidefront2.wav` длительностью около 0.2 с — это скорее одноразовые щелчки; при лупе их стык будет слышен. Unity `AudioSource.pitch` меняет **и скорость, и высоту тона**: настоящего растяжения без изменения высоты звука здесь пока нет; для него потребуется отдельная DSP-обработка/плагин.

### Просвечивание патрона при закрытом затворе

`Hide Mag Top When Slide Closed` (по умолчанию включено) скрывает только **визуальную копию** `MagazineTopRound`, когда затвор закрыт. Видимость рассчитывается по реальному положению `Slide` относительно его начальной позиции, без связи с состоянием курка; магазинный счётчик и подача не меняются. `Mag Top Reveal Slide Fraction` = 0.15 означает показать копию после 15% хода затвора, в том числе при ручном открытии и на задержке. Если верхний патрон всё равно торчит в просвет при открытом затворе, скорректируй `MagazineTopPoint` внутри магазина: скрипт не меняет его положение.

### Отдача очередью из одиночных выстрелов

Раньше раздел `7.1` вычислял усиление по **остаточному target recoil** перед выстрелом. Быстрые `Pos/Rot Return Speed` успевали его обнулить, поэтому даже большое число в `Progressive Recoil Multiplier` часто умножалось на ноль. Теперь отдельный накопитель серии растёт после каждого выстрела (`Progressive Recoil Build Per Shot`, по умолчанию 0.5) и затухает (`Progressive Recoil Decay Per Second`, по умолчанию 0.45 в секунду). Первый выстрел после паузы — обычный; каждый следующий быстрый сильнее: коэффициент **1 + Multiplier × heat ^ Curve**. При `Multiplier = 0.5`, `Curve = 2`, с учётом затухания быстрый второй выстрел получает примерно +8%, третий +30%. Если пауза длинная, серия сбрасывается. `Curve > 1` откладывает усиление до поздних выстрелов. Множители позиции/поворота из раздела `7` продолжают действовать.

В `20. ADVANCED PREVIEW` старый `Recoil` показывает **потолки** — менять `7.1` там было бессмысленно: лимит, умноженный и зажатый в тот же лимит, не меняется. Новый `ProgressiveKick` показывает максимальный/минимальный одиночный kick при условном накоплении серии (`Preview Slider` по модулю задаёт heat от 0 до 1, знак выбирает сторону случайного диапазона). Preview не учитывает движущуюся цель, накопленную отдачу, camera shake и скорость перемещения игрока. Для проверки в Play Mode включи `Debug Progressive Recoil`: Console покажет heat, применённый коэффициент и значения **до/после** ограничителей при каждом выстреле. Если после ограничителей значения не меняются даже при коэффициенте 100, расширь `Min/Max Pos/Rot Recoil` *для теста*, затем верни нужные тебе лимиты: код не снимает их автоматически и не меняет твои настроенные значения.

### Как передать настройки Inspector

Сохрани **свою текущую** сцену в Unity (`Ctrl+S`) и пришли `.unity` из `Assets/Scenes/` (или соответствующего каталога проекта). Если пистолет в prefab, приложи также `.prefab`, а для prefab overrides — сцену; при передаче новых ассетов приложи и связанные `.meta`. В `Project Settings → Editor → Asset Serialization` удобно выбрать **Force Text**, чтобы сохранённые значения читались как YAML. Для быстрой диагностики хватит скриншотов Inspector разделов `7`, `7.1`, `8`, `9`, `19.1` и Transform `MagazineTopPoint`; но скриншоты не заменяют сцену с точными значениями. Старый `Scenes/SampleScene.unity` в этой ветке **не использовать вместо твоей сохранённой версии**.
