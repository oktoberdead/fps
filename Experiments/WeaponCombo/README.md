# WeaponCombo — актуальная сцена и управление

**Рабочая сцена:** `Experiments/WeaponCombo/WeaponCombo.unity`. В ней сохранены твои грубые hip/ADS/slide-pull, положение общего контроллера, hand contact и настройки отдачи. `WeaponCombo 1.unity` — отдельная старая копия; папки `exp/` и остальные сцены `WeaponFeelV2` не были перезаписаны. Не запускай генератор поверх рабочей сцены.

- `Main Camera → MOVE WEAPON + BOTH HANDS (pose alignment)` сдвигает оружие **вместе с обеими руками**. `WeaponAnchor` — неподвижная калибровка; не переписывай его при смене поз. `ColtRoot` локально двигает **только** `TacticalGun` (idle, ADS, slide pull, sway, bob, отдача). `baseIdlePos/Rot` в нулях относятся к ColtRoot, не к общему родителю. `Hand contact offset` смещает только цели кистей относительно пистолета.
- В `Player → WeaponHandCombo` включён **One finger grip for every stance**. Под ним всего два набора слайдеров: для RIGHT (ведущая) и LEFT (поддержка): сгиб пальцев, сгиб и разведение большого пальца. Настрой каждый **один раз** — этот хват используется при стрельбе от бедра, ближнем/дальнем ADS, slide pull и sway. Остальные сохранённые pose-семплы не стёрты; чтобы вернуться к разным хватам, сними флажок. Точки кистей и подсказки локтей пока различаются между позами и плавно смешиваются IK. Они могут потребовать локальной доводки, но **каждый палец в каждой позе настраивать не нужно**. `Preview ADS`/`ADS reach` показывают положение рук без Play; локти отдельно правятся хэндлами при выделенном `Player`.
- В этой сцене включён **camera-space movement sway** только для позиционного sway при движении: `ADS Move Sway Pos X` — вбок (A/D), `Y` — вверх/вниз при движении, `Z` — глубина (W/S) относительно камеры. Существующие числа Amount/Base/Min/Max оставлены как были. Исправление не трогает sway мышью, отдачу, bobbing и `SampleScene`. Учти: при `moveSwayAdsWalk = 0.2` величина `Y Amount = 0.01` даёт лишь около **0.002 м** смещения, поэтому эффект поначалу малозаметен; отдельные лимиты Min/Max также ограничивают его. В рабочей сцене `TacticalGun → Preview Axes` (`applyPosX/Y/Z`) выключены: это флаги только его **редакторского** превью, в Play они не отключают sway.

Для **новой** отдельной сцены есть `Tools → Weapon Feel V2 → Create integrated gun + arms scene`. Генератор копирует всю актуальную `Scenes/SampleScene.unity` и берёт тестовые позы прежде всего из `Experiments/WeaponFeelV2/tests/`, при их отсутствии — из старой `tests/`. Исходные сцены, FBX и настройки стрельбы не меняются. Для уже настроенной сцены генератор **не нужен**.

Это черновая интеграция: после компиляции в Unity проверь хват большого пальца, контакт ладоней и локти в hip/ADS/slide pull. Для окончательных контактных точек нужны визуальные скриншоты — точное совпадение меша без них не обещается.
